# IUVS-NLC
This contains all the code and associated files required to generate the plots in my IUVS paper on noctilucent clouds.

All public data used in the code on the NASA PDS for IUVS FITS files and through JPL for NASA SPICE kernels. Otherwise, files needed to generate plots are included in the associated folder.
